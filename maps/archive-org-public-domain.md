# Internet Archive public-domain sound map

This is a small, conservative map of Internet Archive audio that is explicitly marked **Public Domain Mark 1.0** on the item page. It is meant as a source map for building the reusable sound corpus, not as a claim that every audio item on archive.org is public domain.

```text

│       ├── forest / birds / bees
```

## Important nearby collections that are *not* automatically public domain

### USC Optical Sound Effects Library

Archive.org hosts a very large USC sound-effects collection: rain, thunder, machines, cars, aircraft, footsteps, fire, explosions, animals, sci-fi effects, and more. It is an excellent discovery source, but the collection should **not** be bulk-labelled public domain merely because Archive.org hosts it. Keep its metadata with every candidate and review rights before copying a file into the reusable corpus.

Archive overview:
https://blog.archive.org/2023/05/20/crash-bark-boom-the-usc-sound-effects-library/

### Natural Sounds Field Recording Archive

Identifier: `NaturalSoundsFieldRecordingArchive`.

This one is **CC BY-NC-SA 3.0**, not public domain. Useful for listening/research, but it does not belong in a public-domain-only fixture set.
